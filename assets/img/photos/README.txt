PHOTOS FOR THE BGI SOLUTIONS WEBSITE
====================================

Put your images in THIS folder:  assets/img/photos/

Name each file exactly after its slot (lower case), for example:  img_01.jpg
Accepted types: .jpg  .jpeg  .png  .webp
Nothing else needs to change. When a file with the right name is here, it
replaces the placeholder automatically. Remove the file and the placeholder
comes back.

Optional phone version: add a second file ending in -mobile (for example
img_01-mobile.jpg) cropped for phones. Without it, phones show a centred
crop of the main image.

The spec says every image must be approved (rights, owner sign-off, alt text)
before the site is published. Do not use photos that suggest generic people
are BGI staff or clients.
